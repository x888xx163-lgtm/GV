# ООО «NEW-Контакт» — премиальная версия статического сайта

Файлы:
- `index.html`
- `styles.css`
- `script.js`
- `assets/` — самостоятельно смоделированная SVG-графика: производство, ванны, готовые покрытия, лаборатория, чертёжный CTA.

## Особенности премиальной версии
- тёмный главный экран с золотым/медным акцентом;
- более дорогая визуальная система: крупная типографика, меньше визуального шума, больше воздуха;
- блоки производства, ванн, лаборатории и готовых покрытий;
- интерактивный подбор покрытия;
- форма заявки через `mailto` и скачивание TXT-заявки;
- адаптивная верстка для мобильных устройств.

## Перед публикацией заменить
1. Телефон, email и адрес.
2. Email в `script.js`, переменная `companyEmail`.
3. При желании — SVG-графику на реальные фотографии производства.
4. Блок карты на iframe Яндекс.Карт или 2ГИС.

## Как опубликовать
Загрузите содержимое папки `new-kontakt-premium-site` на статический хостинг.
